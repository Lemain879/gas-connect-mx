# Gas Token MX

Origen: del Hackathon a Token Gas MX
Tras el Hackathon de Stellar Codigo Alebrije surgió Tanko la idea principal era monederos electrónicos para el pago de combustibles y trazabilidad de los mismos, los retos a los que nos enfrentamos actualmente y analizando en el modelo de negocios de Tanko, vimos que actualmente en el sector energético y demás entes reguladores en México (SAT, CNBV, BANXICO) para actividades vulnerables como lo es el pago con Activos Digitales o Stablecoins, hay poca claridad para expedir ciertos boletines por parte de las entidades reguladores, lo cual nos llevo a escalar el proyecto a otro contexto, tanto desde el tipo de clientes, plataformas y modelo de negocios.
(la idea inicial de los monederos no se descarta se tiene con la visión de desarrollarlo a largo plazo conforme la regulación sea clara y nos permita tener una alta competitividad con los monederos electrónicos tradiciones)
