# Gas Token MX

Necesito una pagina perfecta para ecosistema Web 3.0 es una pagina que se llame TOKEN GAS MX. Es una pagina que va ser publicitaria anunciando nuestros beneficios como token, así como también va permitir a dueños de pipas de Gas o de cilindros registrarse para ser parte de la comunidad.                        Utiliza el Slogan Carga seguro, exacto, rápido y a buen precio.                                                                                     Tambien la siguiente frase: Al darte alta en nuestra aplicacion como gasero tienes acceso a las de mil restauranes, zonas habitacionales, edificios de la Zona metrolitana                                                                          También tiene que haber un botón que diga si eres usuario de gas descarga la App que sera un simple boton que te va dirigir a la app.
